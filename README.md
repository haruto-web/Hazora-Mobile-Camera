# Hazora Mobile Camera

Native Android app project for the Hazora hazard-detection dashboard.

## Open in Android Studio

1. Clone this repository or open the local `Hazora-Mobile-Camera` folder.
2. In Android Studio, choose **Open** and select the repository root (the folder containing `settings.gradle.kts`).
3. Allow Gradle sync to finish.
4. Run the `app` configuration on an Android device or emulator.

The project uses Kotlin, Android Gradle Plugin 8.9.1, Gradle 8.13, and requires Android SDK 36 to build.

## Current status

This is the initial Android Studio project scaffold. Camera preview, Wi-Fi onboarding, and a stream endpoint for the dashboard have not been implemented yet.
